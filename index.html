About AutoSphere

AutoSphere is a front-end automotive showcase platform designed to present vehicle information from major manufacturers. This demo is intentionally built without a backend and can be deployed directly to GitHub Pages.

Scroll through the catalog, search by model or brand, filter results, and view details using the modal experience.
